# Aleator

***Fun fact: ALEATOR is latin for "dice player"***

Fan project/game inspired by the popular Hasbro game Yahtzee, not affiliated with the company itself.

Embrace yourself in an interactive game where you roll the dice and score points for the choices you made, will you have a **perfect** run or will you be overconfident and score low?

This project might have the possibility to become a balatro inspired game, let me know if you think if i should try.
